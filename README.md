# Programming Lineage Codex

This repo hosts an interactive grid that visualises 215 programming language roots and more than 900 descendant technologies. Open `index.html` in a browser to explore the codex:

- Filter by any root or descendant name using the search box.
- Click a card (or any descendant pill) to highlight a lineage and surface the full chain.
- Reset the view at any time with the **Reset** button.

All data lives in [`lineages.js`](./lineages.js) and is rendered client-side via [`script.js`](./script.js) with styling in [`styles.css`](./styles.css).
